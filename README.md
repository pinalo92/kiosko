# 🍬 Pica Pica - Kiosco Online (Solo Packs)

Kiosco online **solo para packs** completamente funcional con integración de WhatsApp para compras. Diseño moderno, responsive y optimizado para Netlify.

## 🚀 Características Principales

- ✅ **100% funcional sin backend** - Todo el proceso en el cliente
- ✅ **Diseño responsive** - Perfecto en móviles, tablets y escritorio
- ✅ **Integración WhatsApp** - Pedidos directos al número del kiosco
- ✅ **Carrito de compras persistente** - Guardado en localStorage
- ✅ **Búsqueda y filtros** - Busca y filtra packs fácilmente
- ✅ **Mínimo de pedido configurable** - Validación automática
- ✅ **Notificaciones en tiempo real** - Feedback al usuario
- ✅ **SEO optimizado** - Meta tags y Schema.org
- ✅ **Listo para Netlify** - Configuración automática
